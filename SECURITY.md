# Security

This repository is a non-deployable public case study. The production codebase and operational infrastructure are private.

If you believe you have found a vulnerability affecting RightMatch Namibia, please do not open a public issue or publish technical details. Email **info@rightmatchnamibia.com** with a concise description and a safe way to reproduce the concern. Do not access, alter or retain data that does not belong to you.

RightMatch will acknowledge legitimate reports and coordinate an appropriate response where possible.
